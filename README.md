# To-Do List (Python)

## 📌 Description
This is a simple command-line To-Do List application built using Python.  
It allows users to manage daily tasks easily.

## 🚀 Features
- Add tasks
- View tasks
- Delete tasks

## 🛠️ Technologies Used
- Python

## ▶️ How to Run
1. Download the file
2. Open terminal in the folder
3. Run:
   python todo.py

## 📷 Output Example
1. Add Task
2. View Tasks
3. Delete Task
4. Exit
